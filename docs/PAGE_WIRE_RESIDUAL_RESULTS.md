# 原图线条残差与页面模板：小幅收益，仍未过发布门槛

2026-10-08。本轮没有新模型优化步，完成三个分开记录的训练／开发尝试、全新640页测试与混合线宽反例。最终规则比同页冻结研究基线略好，但产生新的错误，预注册门槛失败；RC0不接入。

## 新观察角度

原图交点补丁来自冻结的图像观察中心，不用GT位置。先估计水平/垂直线条的墨迹轮廓，再按 `H(y)+V(x)-H(y)V(x)` 预测可分离模糊条件下的普通交叉，观察多出的二维墨迹。对四个对角象限取最弱残差证据：低分提议CROSS，高分提议JOIN，中间／非有限值保留原模型判断。

这不是训练后的神经模型，也不是真实电气连接证明。公式依赖线条形状与模糊假设，周围器件、重采样和未知页面风格可以破坏这些假设。

## 三次开发尝试，失败均保留

1. **局部参考线条**：用补丁边缘估计H/V。固定low=.02、high=.12，在256页旧开发集改28个交点，26个改错，修复1页／破坏24页，完整分区98.44%→89.45%。30组训练阈值搜索无一同时达到两类99.95%精度，停止，未进入新留出。另12个独立孤立线条/连接点fixture均能按分数区分；不能据此声称整页可靠。
2. **页面端部参考线条**：从各行右端、各列下端的过伸线段估计轮廓，跨行列取中位数，避开局部器件。训练阈值选择low=.02/high=.08。开发改3个交点、1个改错；修复1页／破坏1页，完整分区仍98.44%，门槛失败。
3. **页面模板＋严格训练校准**：独立协议记录56组阈值，要求两种确定分类在有限训练集上均无观察错误，再最大化确定分类覆盖。复用第二次的训练分数；不重跑训练，不读取旧压力页。选出low=.02/high=.10，确定分类覆盖93.50%，两类训练精度均100%。开发改2个交点、修复1页、无观察误改，完整分区98.44%→98.83%，通过开发准入。

三次使用同一公开train/dev资源，开发不是盲测；第三次还参考了此前开发失败来制定更严格的训练规则。有限训练零错误不等于安全保证。所有阈值在最终新640页生成前固定，后续未根据新留出调阈值。

## 混合线宽边界反例

另构造两个干净6×6页面，仅第一个交点为JOIN。均匀1px线条时，该点分数0.203125，规则正确提议JOIN。混合页面仅第一行/列1px、其余7px，该点分数0，规则错误提议CROSS；两张页面均通过几何检查。

这是共享线条模板假设的构造反例，不是独立真实验证。它明确表明“geometry_ready=true”不能证明页面共享线宽或规则适用。CPU混合页接口也保持 `shared_linewidth_verified=false`、unknown、requires_review=true、无verified_net_groups、automatic_release_enabled=false。

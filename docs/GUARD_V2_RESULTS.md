# 多对比度方向证据与弱线条配准：受控门槛通过

2026-10-07。本轮保持ContrastOnlyReader权重不变，改进几何前端，完成开发准入和640张新留出评估。**受控强模糊主队列通过门槛，剪切/旋转拒绝保持；独立真实精度仍未验证。**

## 方法与保留的拒绝条件

上一轮正常压力34页因方向证据不足被拒绝。本轮不降低3度正交标准，也不忽略已经观察到的倾斜：

1. 保留强对比度方向检查。强证据非正交时直接拒绝。
2. 仅在强证据不足时，将连续墨迹强度轻度平滑，分别在0.18、0.10对比度下提取方向。
3. 至少一档证据充分，且所有充分证据均正交，才继续；证据冲突仍拒绝。
4. 优先采用既有V2图像配准；失败时用弱线条连通区域估计范围，再检查多区域线格一致性。

全过程只接收灰度图，GT程序/变换不传给定位或模型。仍强烈依赖均匀正交3–6线格、外伸线条、原生256px及有限R/C语法，不支持任意布局、IC/OCR/飞线。新方法是已有视觉操作的组合，不声称独创基础算法。

## 先开发、后新留出

先仅使用旧ContrastEdge银行的train4096与validation256检查改进，不读取其旧压力/剪切图像调参。生成新留出时，只读取历史程序计算去重hash，不用于算法设计或预测。

模型固定为上一轮ContrastOnlyReader第4轮权重，187,453参数。本轮新增优化步**0**；没有重新选择checkpoint或根据压力调方向条件。

事前开发门槛：覆盖≥98%、全量完整net分区≥98%。开发256页新方法覆盖/完整程序/分区均100%，通过；旧方法覆盖249/256、完整程序97.27%。

训练4096页新方法通过4079页（99.58%），全量net F1 99.63%、完整程序99.27%。ready线数身份错误train11页、dev1页，完整保留。这说明配准状态不能当作真值；开发模型恰好仍正确，不免除几何异常，也不等于CoordinateConventionFrozen。

旧方法ready224页原本全部程序/分区正确；新方法恢复32页覆盖，没有以关闭几何检查换取接受。新primary ready线数身份错误0。两个方法使用同页和同权重，因此这里的变化可归于几何前端的联合改进；不能单独证明多阈值或连通区域哪一步贡献更大。

仍有一处器件类别误读：case153、slot45，GT `12=C`，预测`11=R`。两者均将上下端子作为独立导线节点，不直接短接，因此该误读不影响本语法net分区，但会影响器件类别/完整程序。不能把net100%写成全部电路内容100%。原始错误保存在`primary-program-errors.json`，没有据此再训或重选模型。

全量诊断对拒绝原图也运行模型；实际入口对拒绝页停止生成程序。主队列新方法全通过，所以此处覆盖与诊断范围一致；不支持队列的模型分数只用于诊断，不代表被自动接受。

## 结果定位与下一步

这轮首次把强模糊覆盖、网络分区和不支持几何拒绝同时推过当前受控门槛。下一步不优先扩网络规模，应从这一前端向更真实的布局/符号定义过渡，并继续检查配准线数异常与器件类型错误。已经揭示的640页只能做开发诊断，不能再次声称首次盲测。

训练/development中的12条ready线数异常仍需追溯；本次新primary0异常不自动解决它们。当前有限语法成功也不能替代整页独立电气监督、人工坐标语义审核或正式评分器。

旧各研究、RC0源码/权重、提交ZIP与25例审核协议SHA保持一致。真实A/B仍0/25，verified designs仍0，CoordinateConventionFrozen仍false，官方evaluator等价性unresolved。该候选不是最终比赛精度闭环。

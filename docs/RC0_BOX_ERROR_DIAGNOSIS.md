# RC0 跨域框错误诊断：先分辨错误来源，再决定是否改框

本诊断只读取 Freeze-B AMSNet 的 25 组缓存预测和原始标注。模型、阈值、RC0 runtime 与缓存均未修改，没有重复推理。它是首次评估后的错误分析，不是新的独立验证，也不代表比赛评分。

## 固定协议

GT 通过已有 `scripts/evaluation_metrics.py` 将 AMSNet `[ymin,xmin,ymax,xmax]` 转为图像左上角 `xyxy`；最终输出由左下角坐标转换回左上角。原始 detector 从 `designator_association.records` 读取，其 bbox 已是左上角坐标。

每个 GT/预测只使用一次，按以下顺序进行最大权重 Hungarian 配对：

1. 同类 IoU≥0.5：严格匹配。
2. 剩余同类，中心归一化距离 `max(|Δx|/GT宽, |Δy|/GT高)≤0.75`：近邻配对。若距离>0.25，归为中心偏移；否则面积比≥1.5 为框偏大、≤2/3 为框偏小，其余为形状或边界不一致。
3. 剩余异类，IoU≥0.3 或中心距离≤0.25：类型不符候选。
4. 无配对 GT 若所有原始候选均无 IoU≥0.3 且中心距离>0.75，归为无邻近候选；否则保留为竞争或类型/几何未决，不强行称作漏检。

这些阈值在脚本中一次声明，不由本组结果拟合。Hungarian 权重为 `1+IoU+0.1/(1+中心距离)`。它保证一对一，但不保证最大配对数量，也不是官方评分实现。权重差≤0.05 的可替代 GT/竞争预测记录为歧义。本组两个阶段均没有达到该歧义标记条件，仍不能据此证明语义对应正确。

共享标注包含177个GT。原始178个候选全部用于几何错误归因，其中137个属于既定共享类别；最终输出46个，全属共享类别。未配对预测单独保留，不把未共享标注的类别直接称作假阳性。

## 真实结果

| 相对标注的类别 | 原始 detector | 最终 semantic output |
|---|---:|---:|
| 同类 IoU≥0.5 | 46 | 10 |
| 同类近邻但中心偏移 | 37 | 36 |
| 中心对、框偏大 | 0 | 0 |
| 中心对、框偏小 | 0 | 0 |
| 中心对、形状/边界不一致 | 0 | 0 |
| 类型不符候选 | 49 | 0 |
| 无邻近候选/输出 | 45 | 131 |
| 竞争或类型/几何未决 | 0 | 0 |
| 合计 GT | 177 | 177 |

原始未配对预测46个，最终未配对预测0个。最终阶段131个无邻近输出不等于131个 detector 漏检：其中36个原本严格匹配的框、49个类型不符候选以及1个中心偏移候选在最终输出消失；另45个在原始 detector 就没有邻近候选。

这与既有固定指标一致：原始共享类别137个预测在 IoU≥0.3 命中83个、IoU≥0.5 命中46个；最终46个预测分别命中46个和10个。错误归因表不是这些 F1 指标的替代品。

## 具体例与边界

**案例177：GND 主要是位置偏移，不能解释为框太大。** GT `[254,484,297,528]`，最终预测 `[252.595,470.343,298.170,511.323]`，中心归一化最大偏移0.345，面积比0.987。两框面积接近，预测整体向上偏移。

最终36个中心偏移全部来自 GND。其中心横向偏移中位数约为GT宽的−0.0086，纵向偏移中位数为GT高的−0.3561，面积比中位数1.2035。原始37个中心偏移中36个也是GND，另1个MOS。这个系统性模式可能来自符号框标注约定，也可能来自跨域检测偏差；尚未做逐图人工标注裁决，不能直接认定检测器的物理中心错误，更不能利用这25组拟合补偿偏移。

**类型偏差集中在 MOS 与供电符号。** 49个异类几何候选中，MOS→C34个、V→C7个、V→other3个；其余5个分别为 R→MOS、V→BJT、MOS→buzzer、MOS→BJT、MOS→crystal。这里是空间配对后可观察的类型不一致，不是人工确认的真实混淆矩阵。案例177中的原始 C 候选与 MOS/供电 GT 接近且无合法位号，最终被过滤；“只恢复名字即可恢复正确元件”并不成立。

**没有证据支持先做通用裁框。** 本协议下没有“中心对但框过大/过小”的病例；主要是 GND 的系统性相对位移、类别不匹配与候选/输出缺失。框边界优化若要继续，应先确认 GND 标注约定，并在开发集之外验证，不应直接按 Freeze-B 的偏移量修补模型。

**真漏检的结论仍有限。** 45个 GT 没有满足预定几何阈值的原始候选，只能称为“观察到的 proposal miss”。远处错误定位候选、错误类别、局部密集符号和标注范围仍可能改变人工判断。对这些 GT 需要图像审阅才能确认真实漏检。最终131个缺输出则混合了检测与身份/输出过滤损失。

## 对下一阶段的含义

同域 PCB 上已观察到的局部 OCR 恢复可以支持 PinTokenNet 的身份研究；AMSNet 同时说明它不能承担跨域 detector 分类、GND 框约定和原始漏候选问题。应将检测召回、类型、位号保留、引脚身份分别作为实验指标，保留 null/abstain，不用文字模型替未确认类型兜底。

Freeze-A 同域独立盲测仍是 RC0 晋升的门槛，本跨域诊断不改变 NO_GO 决策。

## 复现与产物

运行 `.venv/Scripts/python.exe scripts/audit_rc0_box_errors.py`，仅重读缓存并写诊断 JSON。

- 脚本：`scripts/audit_rc0_box_errors.py`
- 逐病例框、距离、面积、类型、阶段、未配对预测及50个输入文件 SHA256：`output/ablation/rc0-box-error-taxonomy.json`
- 3个评价工具单测：`.venv/Scripts/python.exe -m unittest tests.test_box_error_taxonomy`，全部通过；测试覆盖大/小框、中心偏移、类型候选、一对一约束与无候选边界。

AMSNet 仅为共享类别的部分标注跨域压力集；标准化 SPICE 文本分组不能证明设计独立，25组也不是PCB同域盲测。所有诊断保持这些限制，不能宣称已解决真漏检或已经取得新的模型分数。

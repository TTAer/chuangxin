# 可分离渲染协议与固定模型/模板/组合比较

2026-10-07。本轮完成新的可观察性准入协议、4,096新布局GPU训练和提前登记的模型/模板/组合评估。**简单模板在此受控renderer上优于学习模型；神经模型未过压力门禁。**这不是官方比赛或独立真实原理图成绩。

## 新实验边界

上一轮发现“CROSS→JOIN改变电气关系却图像相同”。本轮新建`render_separable`，原生256px，连接点最后绘制，半径`max(6,width+3)`，使点超出横/竖线条的覆盖区域。仍是固定网格、竖向R/C、无OCR/IC/飞线语义的有限语法。

准入检查用16张单独fixture页面、线宽1–7、逐一替换活跃交点/区间指令，共**5,817次反事实比较，0次完全同像素碰撞，最小差异24像素**。只检查干净栅格、单指令变化和有限fixture，不等于噪声下可识别、全语法无碰撞或人类已审核。检查页面与训练/开发/压力队列分开。

旧renderer、旧压力集及所有冻结数据均未修改。所有新程序与两轮旧银行的tiny/train/dev/stress排除完全重复；本轮各队列也不重复。新输入分布的成绩不能与旧队列直接相减归因模型提升。

训练前登记压力门禁：net-pair F1≥95%、完整net分区≥90%。模板和组合规则也在训练前保存`output/separable-circuit-audit/protocol.json`：

- 保守筛选仅保留模型与模板完整程序一致的页面，报告覆盖及错误，不自动晋级verified。

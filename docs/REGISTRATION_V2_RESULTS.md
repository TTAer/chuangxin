# 多区域亚像素线格定位：开发准入与新的留出诊断

2026-10-07。本轮不重训模型，改进只读图像配准，完成训练/开发准入和576张新页面的固定评测。**配准覆盖显著改善；模型粗线识别仍未过门槛，ready不能识别所有不支持页面。**

## 改进及输入边界

旧方法在3像素宽的单一区域对二值线条求中心，细线及缩放插值会导致断裂、额外峰和间距检查失败。新方法在左右/上下外伸区的两组窄带上平均连续墨迹强度，平滑剖面、加权求亚像素中心，再用最小二乘拟合线格，检查多区域位置一致性及残差。

仅接收完整灰度图；不读取GT变换、程序、box、端点或net。仍假设3–6条均匀、正交、可见外伸的线条，支持全局横纵独立缩放和平移，不支持自由布局、剪切、旋转、OCR/IC/飞线。配准状态是算法输出，不是人工验证。

算法在旧train/validation上检查；没有读取旧pressure用于改进，也没有搜索阈值或修改模型。新算法通过开发门槛后，才固定新留出协议和评分。所有旧源码、银行、权重及报告保留原SHA。

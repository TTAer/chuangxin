# 从固定坐标走向图像配准：同页对照与新训练

2026-10-07。本轮引入全局平移与横纵独立缩放，完成图像配准、冻结模型同页对照、开发门禁触发的新GPU训练和压力拆分。**配准有效，但覆盖不足；新模型尚未跨过完整页面压力门槛，保留研究原型。**

## 这次真正改变的输入

过去模型和模板知道所有线条都位于固定像素坐标。本轮先在原生256px visible-dot renderer上生成图，再加入全局横纵独立缩放、平移、模糊和噪声。其电气程序仍属均匀正交网格、竖向R/C语法；没有任意器件布局、旋转、弯线、OCR、IC或飞线标签，不声称已做自由布局解析。

`register_image(image)`只接收灰度图。在左侧/上侧线条外伸区扫描可见横线/竖线，估计间距、数量、横纵scale和translation，再逆变换至规范坐标；不读取每页GT program、端点、box、net或生成变换。线数不在3–6、间距不均或墨迹不足时配准失败，保留原图。

这种算法有强先验：均匀线格与可见外伸区。`ready=true`只表示通过算法检查，不等于geometry reviewed或人工真值。生成变换保存在NPZ隔离字段，仅用于最终误差诊断，不用于配准/模型预测。

## 当前判断

这轮真正推进的是把已知像素坐标变成图像可估计的坐标，同时明确覆盖代价。主问题已收敛到线条外伸探测的覆盖和配准后符号的尺度/插值敏感性。下一次研究应先在训练/开发错误中做原因分型，再固定更真实的线条检测或尺度一致输入；本轮压力已揭示，不再宣称首次盲测。不能继续把同语法小模型训练当作独立设计验证。

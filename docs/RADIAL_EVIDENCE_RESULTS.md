# RadialEvidenceNet：局部形状读取与高置信纠错的失败边界

2026-10-07。本轮实际完成新架构 GPU 训练和两次独立合成留出试验，直接替换与保守纠错均未过门槛。保留上一轮 OrderedV2 和 RC0，不把新模型接入比赛输出。

## 新角度与架构

原模型共享整页特征、先采样再分类。新模型直接读取 33×33 交点图像，用 8 个同心环 × 8 个角度扇区的墨迹均值作为输入；共享扇区 MLP 后以 mean/max 汇总，并独立保留中心墨迹强度。共 3,522 参数，没有 Transformer、整页共享卷积或网络 query。

分别训练两个同架构模型：raw 在图像观察到的交点中心取局部图，采用横纵线间隔中位数估计全局尺度；canonical 在 OrderedV2 非均匀校正图上取局部图。两者训练预算和数据一致，隔离局部坐标拉伸的影响。像素离散下四分之一转动不变性随机输入检查最大 logit 差 1.49e-8；这是结构检查，不是识别精度证据。

## 双视图高置信纠错：另一批新页面也失败

## 结论与工程状态

本轮证明 tiny 可拟合和开发交点100%不保证整页收益；两种相关视图的高置信一致也会共同犯错。受控强模糊失败既可能涉及局部特征信息压缩，也可能涉及训练/留出分布变化，尚未用独立实验拆分原因，不能直接宣称唯一根因。

直接替换和双视图纠错均标记为 FAILED_GATE / RESEARCH_ONLY，自动接入关闭。独立 CPU raw/canonical 候选路径与 consensus 候选/旋转拒绝路径已检查；结果始终 unknown、需审核、无 verified net groups，consensus 的 automatic_release_enabled=false。

本轮新增合成程序共 5,124 页（包含训练、开发、tiny 与两轮留出），不是5,124个独立真实设计。源码、数据、权重、训练曲线、评估协议和负例冻结；前序研究 SHA、RC0源码/包和人审协议锁未变。Reviewer A/B 无新增真实输入，verified designs=0，官方 evaluator equivalence unresolved。

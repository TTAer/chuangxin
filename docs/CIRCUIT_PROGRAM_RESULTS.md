# CircuitProgramNet-H：整图到可执行电路程序的训练结果

2026-10-07。完成新的整图程序架构、六类外部来源图像预训练与8,192张程序图主训练。**同分布开发集可完全拟合，粗线压力集失败；本版冻结为受控语法研究原型，不进入比赛基线。**

## 方案变化与实际训练

此前的PortLift以已知导线图和端口为输入；本轮从完整128×128灰度图预测68条指令，再由执行器构建导线网络与R/C器件。输入不含每页GT端点、导线图、器件box或net标签，但有很强的固定网格与渲染位置先验。架构含CNN、只读图像的横/竖线数量头、渲染位置锚定头、两层Transformer程序解码器及类型语法投影。详见[架构与数据说明](CIRCUIT_PROGRAM_ARCHITECTURE.md)。

模型有**509,636参数**。RTX 4060 Laptop GPU执行；本轮图像预训练从随机encoder开始，没有使用旧研究模型权重。主模型只继承本轮图像预训练encoder/projection，其他头重新初始化；tiny训练权重不转入主训练。

| 实验 | tiny结果 | 是否执行主训练 |
| --- | --- | --- |
| V1全MASK训练 | 一次预测可以全对，六步自由生成F1 62.90%、完整程序0% | 否 |
| V2混合MASK上下文 | 六步F1 93.25%、3/4完整程序 | 否 |
| V3位置锚定 | 第350步4/4，第400步数量预测退化、1/4完整程序 | 否，按原最终门禁停止 |
| V4图像数量前缀+锚定+cosine tiny | 首次登记通过第100步；第350、400步仍4/4 | 是，固定12轮 |

V4事前登记每50步检查，任一登记检查点4页完整程序及分区全对才进入主训练；最终400步也通过。V1–V3日志与停止结果保留，不回改为通过。

实际执行图像预训练：V1的26,718裁剪4轮836步，V2扩至37,918裁剪2轮594步，共1,430优化步。四版tiny各400步，共1,600步；V4主训练8,192整图×12轮、batch32，共3,072步。**本轮合计6,102优化步**。四版训练脚本耗时合计约305.87秒，V4约217.49秒；不含下载、数据准备与诊断。V4峰值CUDA allocated约1.009GiB，不等于整机显存占用。

## 新增数据与实际用途

新增[LogicBench-1K](https://github.com/tkcl-research/LogicBench1k)固定commit的700张官方train JPEG和700份作者JSON；700张全部解码校验，100 val及200 test图像未读取。700图形成11,200裁剪，已实际进入V2图像预训练。作者标签是有向逻辑门图，与pin/net超图不同，JSON保留隔离，不冒充电气监督。CC BY 4.0及作者署名记录在架构文档和intake中。

[CI2N](https://github.com/LAD021/ci2n_datasets)作者train扩到681张PNG/JPG，实际下载并记录SHA；精确像素去重/已知留出排除32张，649图形成10,384裁剪进入预训练。此前64张的取得记录不另外累加为独立图。

最终六类外部来源PCBnet、AITEE、CGHD、OpenSchematics、CI2N、LogicBench合计**2,282张像素准入来源图**；不是2,282个独立设计。外部裁剪36,286，加自建裁剪1,632，共37,918。只在图像预训练使用这些图；电气程序监督来自新建编译器。保留来源train划分、精确去重与已知留出排除，未证明历史设计家族独立。

Netlistfy要求登录并分享联系信息，本轮未获取；CircuitSense响应失败，其他查到的数据来源也未形成新增训练准入，均不计入训练规模。没有训练Freeze-A或官方GT10。

## 固定评测结果

train/dev/stress使用不同seed，并排除完全相同程序。开发集参与检查点选择；压力集未参与选择。12轮全部执行，预登记排序为开发net-pair F1、完整程序、all-MASK CE；最终选择**第11轮**，不是第12轮。第12轮开发分区回退到70.70%，完整程序69.14%，说明优化有不稳定性，不能把选定成绩当作训练全过程稳定。

| 固定256页队列 | 网络关系micro F1 | 器件类型+位置F1 | 完整net分区 | 完整程序 |
| --- | ---: | ---: | ---: | ---: |
| 同分布开发：六步生成 | 100% | 100% | 100% | 100% |
| 粗线+模糊+噪声压力：六步生成 | 29.43% | 58.34% | 0% | 0% |
| 压力：语法约束单步生成 | 29.87% | 57.32% | 0% | 0% |

压力六步TP8,285、FP34,735、FN4,993：主要表现为错误合并，但也有漏连接。横/竖数量100%正确，不能把数量正确当作网络正确。压力裸单步argmax有255/256非法程序；语法约束后合法性由规则保证，不是模型自主学会的可靠性。

这些是固定编译器的导线节点关系和器件位置指标，**不是官方scorer或真实页面精度**。没有复杂IC、pin number/name、文本、跨页/飞线语义、自由布局、横向R/C；固定网格上的同分布100%不代表真实PCB解析100%。

## 固定检查点诊断与可检查产物

| 对照 | 同分布开发net F1 | 压力net F1 |
| --- | ---: | ---: |
| 六步生成 | 100% | 29.43% |
| 语法约束单步生成 | 100% | 29.87% |
| 空白图像 | 0% | 0% |
| 反序配对图像/真值 | 18.98% | 20.05% |

模型依赖图像，但没有去噪多轮相对单步的收益证据。对已经公开结果的压力程序作清洁重绘，只用于定位失效：线宽1/2均100%，线宽3降至30.94%、完整程序0%。这是同程序反事实诊断，不是新的独立验证，也没有用于重选checkpoint或继续训练。粗线会改变R/C笔画及点形态，局部重叠可能降低可观察性，当前实验不能把全部下降仅归为模型风格偏移。

数量头对MASK/其他程序上下文完全一致；首4压力页CPU/CUDA float32生成相同。执行器单独验证孤立电阻不能把两个端子短接。固定前8开发及前8压力输入/真值/预测图保存在`output/circuit-program-audit/*-first8.png`，没有按结果挑选。

独立图像入口`scripts/predict_circuit_program.py`已在首张压力图CPU运行，无GT输入，输出JSON与规范线宽1重绘。这个入口仅接受128×128研究语法图，始终标记`requires_review=true`；不生成冒充官方比赛提交的结果。示例命令：

```powershell
$env:PYTHONPATH=(Resolve-Path .deps).Path
& D:/Python313/python.exe scripts/predict_circuit_program.py output/circuit-program-audit/stress-first.png --output output/circuit-program-demo-copy
```

## 当前结论与下一阶段

整图程序预测的可拟合性成立，但本版绘图风格泛化门槛失败，不增加epoch、规模或去噪步骤。下一次若恢复研究，应先独立设计能够保持符号可观察性的渲染分辨率/笔画间距与多样布局协议，先做可识别性和简单视觉基线，再训练；已揭示的压力页只能成为开发诊断，不能重新包装为首次盲测。

RC0保持冻结，比赛包及历史研究SHA校验单独保存。真实Reviewer A/B仍0/25、verified designs仍0、坐标约定未冻结、官方evaluator等价性unresolved。新数据获取和训练没有替代这些证据。该版是研究产物，不声称竞赛得分提高或最终可提交精度已闭环。

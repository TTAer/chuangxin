# 新版审核工作台

直接打开：[审核者 A](http://127.0.0.1:8767/review-studio/index.html?pass=A) · [审核者 B](http://127.0.0.1:8767/review-studio/index.html?pass=B)。也可双击项目根目录的 `启动审核工作台.cmd`，在默认浏览器打开。建议使用较宽的桌面浏览器窗口；窄窗口会将队列、画布和表单纵向排列。

## 实际操作

1. 输入自己的姓名或唯一 ID，点击“开始 / 恢复草稿”。以后使用相同 ID 和相同遍次恢复。
2. 在左侧选择案例。滚轮缩放，空格按住拖动；选择主体边、外端或接点后点击标点，拖动已有点修正。右侧 × 删除单个点，撤销按钮回退本例编辑。
3. 在右侧选择实际观察结论、方向与候选身份。看不清时保留未确定、歧义或连续无边界；不可见编号留空，无需凑齐三个点。
4. 点击“完成本例并下一例”。回改内容会将该例恢复为待完成，需再次完成。草稿自动保存在当前浏览器，不会自动成为独立验证真值。
5. 点击“导出审核 JSON”，保存文件。若内置浏览器不提示下载，点击“复制 JSON”，粘贴到文本编辑器并保存为 `.json` 文件。导出包含未完成草稿，左侧完成数不会把它们算作已审核。

快捷键：`1/2/3` 选择点类型，`4` 拖动画布，`Q/E` 切换案例，`F` 适配画布，`Ctrl+Z` 撤销，`Ctrl+Enter` 完成并继续，`Ctrl+S` 保存本机草稿。输入框内保留正常输入行为。

两位实际审核者使用不同 ID、各自的 A/B 入口；不提前讨论，不导入另一人的记录。查看参考后再标点的情况会如实保留，撤销不会消除已记录的提前参考暴露。图层和参考默认在切换案例时恢复原始像素、隐藏参考。

本机草稿随浏览器/profile不同而分开，清理站点数据可能丢失草稿；请定期导出备份。工作台没有远端账号或上传服务。

## 接入现有审核流程

新页面导出仍是 `pin-geometry-review-v2`，坐标为原图左上角整数像素，case evidence SHA、protocol和25例保持一致。原 V2 页面、代码、协议锁及图像没有修改。新界面以旁附 UI 实现，不重置协议锁；输出附有UI版本与原协议锁hash。

将两份真实导出文件放入工作区后，仍使用：

```powershell
.venv/Scripts/python.exe scripts/prepare_review_handoff.py --reviews data/research/human-review-A.json data/research/human-review-B.json
```

同一实际审核者导出的多个版本不要同时提交为两个独立 reviewer。先选各自最终版本。

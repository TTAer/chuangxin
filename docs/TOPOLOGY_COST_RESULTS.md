# 单点反事实拓扑代价训练：有相对信号，但未改善冻结基线

2026-10-08。实际完成普通CE与拓扑代价加权CE两组GPU训练，并评估全新640页。加权减少了相对普通CE的错误连接，但仍落后于冻结基线，预注册门槛失败，禁止自动接入。

## 新监督角度

只读取既有 tiny/train/validation 的程序真值：逐交点翻转 CROSS/JOIN，其他GT指令固定，执行电路语法，计算新增上三角关系FP+FN。用 `1+min(FP+FN,128)/32` 加权交叉熵，再除以训练集权重均值。零拓扑代价样本仍保留权重1，没有忽略其局部语义。

这是GT单点反事实敏感度加权，不是精确可微整图损失，也不提供推理期图上下文。多个错误发生时并不保证这些代价可加。GT图、权重与标签仅用于训练和开发评估，文件推理只读图像。

固定 SpatialEvidenceNet，17,050参数；同随机初始种子20261091、同补丁顺序、无新增模糊训练、同AdamW/lr.001。两组各tiny400步后最终96/96正确；重置初始权重，完成8轮、1,304主优化步。共3,408已完成优化步，无中断。

使用4,096既有合成训练页的83,139 raw补丁，未新增外部真实数据。逻辑batch512、micro128，GPU分配上限20%，没有停止其他既有GPU任务。

开发选择规则预先固定：先最小化清晰／固定额外模糊开发的较大单点错误代价，再提高准确率，首个最佳轮次保留。模糊开发seed20261092对两组相同。

## 当前决定

状态 **FAILED_PREREGISTERED_GATE / RESEARCH_ONLY**，自动接入关闭。独立CPU risk候选及旋转拒绝路径已验证；输出始终unknown、requires_review=true、verified_net_groups=null。

本轮支持“训练代价能抑制部分损害”的有限结论，不支持“已解决全局拓扑误合并”。局部模型没有接收完整图上下文，训练期GT敏感度只改变样本重要性；这是后续值得检验的表示缺口，不是已证明的唯一根因。

后续若继续，应先以已预测而非GT图上下文构造上下文条件模型，并做小样本可拟合与独立开发检查；该方向尚未实现或验证。本轮权重、成本监督、协议与全部失败结果冻结，RC0和前序研究保持原样。真实双人审核无新增输入，verified designs=0，官方evaluator等价性 unresolved。

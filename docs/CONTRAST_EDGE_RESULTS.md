# 全页方向检查与对比度/梯度模型：同预算成对实验

2026-10-07。完成新的几何检查、4,096布局成对GPU训练、强模糊压力及剪切拒绝评测。**几何检查通过后的识别形成稳定信号；全量几何覆盖不足，梯度通道没有新增整页收益，两版均保持研究资产。**

## 本轮改进与固定边界

上一轮V2仅检查外伸区域线格，剪切页仍可能误ready。本轮新增全页Hough线段方向证据：水平/垂直支持不足则保留unknown；长度加权中位方向偏离正交轴超过3度则拒绝；通过后再运行只读图像V2配准。使用图像，不用GT变换或程序；仍限定均匀正交网格和可见线条外伸，不是自由布局解析器。

两组模型采用同一银行、seed和训练预算，均随机初始化：

- ContrastOnlyReader：逐图估计背景，对比度归一化，再使用已有共享卷积及槽位头。
- ContrastEdgeReader：同一对比度处理，再加入有符号水平/垂直Sobel梯度通道，保留相同槽位/数量任务。

没有加载旧监督模型进行新训练，也没有因压力成绩改epoch、阈值、输入或检查点。梯度特征是既有图像表示方法，本轮不声称独创算法。

## 数据、协议与实际训练

银行`data/processed/contrast-edge-v1`共4,868张新程序图，排除全部前4轮银行及V2的576张留出程序，也跨本轮队列排除重复：

| 队列 | 程序数 | 设置 |
| --- | ---: | --- |
| tiny | 4 | 训练风格 |
| train | 4096 | scale0.55–1，线宽1–7，blur0.2–0.8，亮度0.5–1、noise2–5 |
| validation | 256 | 同训练风格，独立程序 |
| stress | 256 | scale0.55–0.85，未见blur0.9–1.2，线宽1–7、noise5 |
| shear | 256 | 新剪切0.12–0.2，独立不支持几何诊断，不训练 |

全部仍是合成原生256px有限语法；没有新增外部数据下载、人工标签或verified design。

训练前保存银行协议与审计协议。每版tiny400步最终4/4完整程序/分区通过后，回到随机初始权重，固定8轮、batch16；每版400 tiny+2048 main步，共**4,896优化步**。开发F1再完整程序选模，Contrast选第4轮、Edge选第5轮。两版全8轮实际执行。

Contrast 187,453参数、约90.14秒；Edge 187,741参数、约86.76秒；耗时不含准备/评估，不据几秒差判断速度优势。两个运行峰值CUDA allocated均约383–387MiB。实际模型身份保存在各`model-definition.json`，路径适配复用旧训练器通用protocol时，以该文件及银行协议说明架构。

初次准备因OpenCV返回线段数组形状差异中止，修复为reshape后重跑，保留`output/contrast-edge-preparation-initial-error.log`。没有将未完成银行计入训练，也未覆盖旧实验。

事前模型压力门禁为全量net F1≥95%、完整分区≥90%；几何门禁为正常压力覆盖≥90%、剪切接受≤5%。**均未整体通过。**

模型压力TP/FP/FN分别为Contrast 13,076/765/1,840，Edge 13,261/841/1,655。Edge多了一些正确关系，同时增加76个FP，没有完整页面收益。仅单seed成对证据，未证明跨seed优势；不推荐因0.46个百分点关系分差增加默认复杂度。

全量诊断保留几何失败原图并运行模型，便于看错误；实际文件入口对失败页停止预测，因此这些全量诊断分数不等于可自动提交覆盖。

| 队列 | ready/总页数 | 覆盖率 | 两模型ready完整程序/分区 | 模板ready完整分区 |
| --- | ---: | ---: | ---: | ---: |
| 开发 | 249/256 | 97.27% | 100% / 100% | 86.75% |
| 强模糊压力 | 222/256 | 86.72% | 100% / 100% | 87.39% |
| 剪切 | 0/256 | 0%（正确拒绝） | 无接受样本，不定义精度 | 未作支持域模板认证 |

ready是图像算法筛选，不用GT选页，但不等于独立认证。开发有1页ready线数身份与生成GT不一致，尽管模型程序正确，也不能把几何状态当作真值。压力ready线数身份错0。

同一批新剪切页，未加方向检查的V2接受72/256，新检查接受0/256。这是有限受控样本上的0观察错误接受，不是外部分布零风险。

正常压力的34次拒绝全部因全页方向证据不足；未加方向检查的V2可配准234页，因此新检查额外拒绝其中12页，另22页原V2也无法配准。不能把低错误接受率与高覆盖混淆。开发拒绝7页中4页方向证据不足、3页多区域线格不一致；train通过4001/4096。

当前几何门槛不足明确在覆盖，不能靠把34页删掉后宣称整体通过。也不能在没有方向证据时直接放行恢复覆盖，因为剪切诊断已经证明V2存在错误接受。

空白图压力两版完整程序/分区0%，net F1约15.15%；识别依赖图像。程序合法性由类型规则保证，不当作自主电气理解。未知器件、文本、IC、跨页/飞线和官方评分仍不在本实验范围。

## 注册范围与失败处理

固定尺度 `144/25.4 px/mm`，零偏移，容差 **0.25 px**，只验证 CAD 当前 unit 与公共 unit 的矩形主体及可见非零长度引脚。逐条外端/内端与 PDF 原始矢量线比较，支持端点反向；不拟合平移、尺度，不进行亚像素优化。成功实例最大边/线误差约 **0.0000977 px**，该量仅表示矢量数值一致性，不是识别精度。

完整尝试记录在 audit 的 `registration_attempts`：实际涉及 20 个 CAD 源页、37 次 CAD/PDF/page 尝试，其中 16 次为零注册结果。没有成功注册的 CAD/PDF 配对不输出像素标注；无矩形主体、非 U 前缀、隐藏和零长度 pin、未满足匹配误差的实例不混入成功池。成功配对只能证明局部几何对应；某个旧修订 PDF 也可能包含相同局部 IC，尚需全页修订/标题块核对。

这批成功实例旋转角均为 **0°**，因此没有“已验证旋转实例”的证据。26 个去重主体无 mirror，1 个 MCP73831 实例具有 `mirror y`；其主体与五条 pin 均通过原 PDF 矢量注册，并看图核对 pin 编号/名称位置。对称符号的线段匹配不能单独证明镜像身份，因此不据此自动批准其余实例的 number/name。

## 标签级别

批量 annotation 的主体与引脚点属于已注册几何候选；key/name/number/name 来自 CAD，默认仍为**未核对像素可见性的候选字符串**。CAD property 与 project reference 不一致时 key 留空，并保留所有候选；其中一例 AP3012 的 U1/U5 冲突仍需使用此前已经核图的 U5 记录，不能凭字符串排序直接消解。

`pdf_text_layer_unassigned` 原样保存 PDF 原生可抽取文字框，本次 15 配对累计 1,595 条，尚未去重、分配 component/pin 或逐字核图。部分 PDF 文字为矢量笔画，该字段可为空；非空也不能冒充已完成监督 token，不得将 CAD 中的隐藏名称当作图像中可见名称。

本轮额外看图核对 Portability Shield 的镜像 **U3/MCP73831**：5 个引脚，12 个字符串，保存在 `ic-00-visual-review.json`。number/name 为 1/STAT、2/GND、3/VBAT（BAT 下标）、4/VIN、5/PROG。文本框为粗粒度视觉边界，记录原像素与裁图 SHA；这是编码代理的局部视觉复核，**没有独立人工审核**。其余 IC 仍待同样的逐实例转录，所有页面仍未标全。

## 来源和就绪门槛

每条 annotation 保留 GitHub 仓库来源、CAD/PDF/image SHA 与许可文件路径/SHA。记录许可文件不等于已完成范围审核：硬件、第三方库、图标与衍生物的归属和再分发条件须按来源审核，素材仅留在本地来源池，不加入比赛提交包。

官方160/40、PCB55、10GT与历史训练图像缺少完善设计族来源，字节不重用不能证明设计独立。不得把仓库数换算成独立设计数，不得将这些候选用于训练或调参。下一步先为 10–15 个实际不同设计完成设计族排除、全页 component/key/body/pin/number/name 标注和独立审核，冻结像素与真值 SHA 后才进行第一次推理；Net 可留待下一阶段。当前尚未满足该阶段门槛。
